## ⚠️ 安装时的安全提示（看一眼能省你两分钟）

本应用**没有购买代码签名证书**（个人开发者购买证书的成本较高），所以从浏览器下载的安装包在首次运行时，Windows 会弹出蓝色的提示：

**「Windows 已保护你的电脑」**（英文系统为 *Windows protected your PC*）

这是 Windows 对**所有「没有签名、下载量还不高」的程序**的统一处理方式，**不代表文件有问题**。安装时这样做：

1. 点击提示框里的 **「更多信息」**
2. 点击随后出现的 **「仍要运行」**
3. 正常走安装流程即可

如果你想彻底避开这个提示，**用上面的微软商店版本** —— 由微软签名，不会有任何警告。

> 另外说明：应用**装好之后的自动更新不会再弹这个提示**。因为更新包是应用自己下载的、不经过浏览器，不带「来自 Internet」的标记。也就是说这个提示你只需要面对一次。

## 功能

**📥 文件中转站** —— 拖进去先放着，要用时再拖出来

不用复制文件、不用起名字、不用建文件夹。中转只记录路径引用，所以再大的文件也是瞬间加入。支持两种形态：悬浮球，或贴在屏幕顶部的长方形栏（拖动文件靠近会自动展开）。

**📋 剪贴板历史** —— 复制的文字和图片都留得住，随时翻回去

**📡 局域网快传** —— 同一个 Wi-Fi 下，把文件直接甩给手机或另一台电脑

**🌐 中英双语** —— 首次启动自己选，之后也能在设置里随时切换

## 隐私

## ⚠️ About the security warning when installing (saves you two minutes)

This app is **not code-signed** (a signing certificate is costly for an individual developer), so when you run an installer downloaded from a browser, Windows shows a blue prompt:

**"Windows protected your PC"**

This is how Windows treats **every program that is unsigned and not yet widely downloaded**. It does **not** mean the file is unsafe. To install:

1. Click **"More info"** in the prompt
2. Click **"Run anyway"** that appears below
3. Continue with the normal installation

If you would rather avoid this entirely, **use the Microsoft Store version above** — it is signed by Microsoft and shows no warnings.

> Note: **auto-updates will not show this prompt again.** Update packages are downloaded by the app itself (not through a browser), so they carry no "downloaded from the Internet" mark. You only face this prompt once.

---

## Features

**📥 File drop shelf** — Park a file now, pick it up later

No copying, no renaming, no folders. Only a path reference is stored, so even huge files are added instantly. Two forms: a floating ball, or a bar docked to the top of your screen (it expands when you drag a file near it).

**📋 Clipboard history** — Text and images you copied stay within reach

**📡 Local Wi-Fi transfer** — Send a file straight to your phone or another PC on the same Wi-Fi

**🌐 Bilingual UI** — Choose Chinese or English on first launch; switch anytime in Settings

---

## Privacy

**Everything stays on your machine. Nothing is uploaded to any server.**

- No account required
- No usage data collected
- The shelf only stores path references, never file contents
- Clipboard images are saved in the app data folder (D: by default)

---

## Requirements

- Windows 10 / 11 (64-bit)
- ~300 MB of disk space

---

## About updates

The EXE build has a built-in auto-updater: it checks once per launch and downloads new versions quietly in the background. When the download finishes, click "Restart to update" — the app installs and reopens automatically.

If it has already checked that day and found nothing new, it won't make another request.
